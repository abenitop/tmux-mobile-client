## Short description (≤ 80 chars)
Your tmux sessions on your phone, over SSH. Real terminal + chat view.

## Full description

Tmux-Max Mobile puts your tmux sessions on your Android phone, over SSH.
Connect to any server, attach to a tmux session in control mode, and get a real
terminal — driven by your normal Android keyboard (no cramped on-screen keyboard).

### Terminal
- Real terminal rendering — colors, formatting, no raw escape codes.
- Raw and compose input modes; gestures for Esc/arrows, plain-text tokens for
  special keys (`^c`, `:esc`).
- System keyboard only. Your Gboard / SwiftKey / voice input stays the input
  surface — no custom on-screen keyboard, ever.

### Chat view (optional)
- Render Claude Code / Hermes sessions as WhatsApp-style chat bubbles.
- Inline diff cards for file edits, and detected permission prompts.

### Security
- Trust-on-first-use host keys — a changed server key is rejected into a
  warning screen instead of connecting silently.
- Passwords are stored on-device via the Android Keystore and never leave your
  device except to connect to your own server.

### Multi-host
- Save multiple servers, each with its own host, username, password, and tmux
  session name.

Open source (GPL-3.0). No accounts, no analytics, no ads, no trackers.
